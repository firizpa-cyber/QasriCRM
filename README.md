# QasriCRM

Высокоскоростная CRM-система для недвижимости с интерактивной шахматкой, 3D/2D-планировками и умным контролем броней. Премиальный визуал, автоматизация продаж и полная прозрачность сделок в едином интерфейсе.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run start`

## Build

```bash
# Development build
npm run build:staging

# Production build
npm run build:prod
```

## Code Quality

```bash
# Lint
npm run lint

# Type check
npm run typecheck
```
