# QasriCRM

A web CRM interface for real-estate workflows, built with Angular and Taiga UI. The project is structured as a TypeScript application with dedicated development, production build, lint, and type-check commands.

## Tech stack

- Angular 21
- Taiga UI 5
- TypeScript
- RxJS
- Zod
- Tailwind CSS
- ESLint, Prettier, Stylelint
- Vitest

## Requirements

- Node.js (use a version compatible with the installed Angular toolchain)
- npm

## Getting started

```bash
git clone https://github.com/firizpa-cyber/QasriCRM.git
cd QasriCRM
npm install
npm run start
```

The development server is started through the Angular CLI.

## Available scripts

```bash
npm run start
npm run build
npm run build:staging
npm run build:prod
npm run lint
npm run typecheck
npm test
```

## Code quality

Before submitting changes, run:

```bash
npm run lint
npm run typecheck
npm test
```
